## Brand & Style

This design system defines an elite, engineering-grade digital agency aesthetic tailored for high-growth tech founders, enterprise innovators, and venture-backed startups. The visual ethos merges the razor-sharp clarity of modern Swiss typography with high-fidelity digital craftsmanship—evoking authority, kinetic energy, and pristine product execution.

The style fuses **Modern Corporate Minimalist Structure** with **Subtle Luminous Glassmorphism**:
- **Atmospheric Clarity:** Airy, ultra-clean white and ice-tinted canvases create spacious room for dynamic showcase assets and metrics.
- **Electric Vector Luminance:** Drawing directly from the logo mark’s chromatic layering, interactive surfaces and brand anchors leverage vibrant electric blues and cobalt gradients, energized by subtle cyan focal highlights.
- **Micro-Precision Detail:** Frosted glass panels, translucent white borders, delicate directional gradient rims, and tinted ambient diffusion shadows deliver a tactile, cutting-edge software feel without visual noise.

## Colors

The palette is engineered around high-energy optical luminance grounded by deep architectural navy:

- **Primary (`#1366FF` - Electric Cobalt):** The flagship brand color. Drives core calls to action, focus rings, active navigation items, and primary visual anchors.
- **Secondary (`#00C6FF` - Vivid Cyan Glow):** Used as an accent and gradient highlight terminator. Imparts futuristic luminescence in subtle gradient borders, badges, and progress indicators.
- **Tertiary (`#252BFA` - Deep Ultramarine):** The chromatic counterpart seen in the overlapping geometry of the logo mark. Powers deep gradient stops, active press states, and selected chip fills.
- **Neutral (`#060A23` - Midnight Navy):** Replaces harsh standard blacks. Serves as the primary typography baseline, ultra-high-contrast button fills, and structural framework lines.

### Supporting Canvas & Glass Foundations
- **Base Canvas:** `#FAFCFF` (ultra-clean ice white).
- **Surface Elevation 1 (Card Base):** `rgba(255, 255, 255, 0.82)` backed by `backdrop-filter: blur(16px)`.
- **Surface Outline / Gradient Rim:** Linear gradient from `rgba(19, 102, 255, 0.28)` to `rgba(0, 198, 255, 0.08)`.
- **Text Muted / Subtitle:** `#5A6584`.
- **Border Default:** `rgba(6, 10, 35, 0.06)`.

## Typography

The typographic hierarchy relies universally on **Plus Jakarta Sans**, utilizing its geometric clarity, wide horizontal apertures, and humanist polish.

- **Display & Large Headlines:** Set at tight letter tracking (`-0.03em` to `-0.02em`) with heavy font weights (`700` and `800`) to echo the authoritative geometric stance of the wordmark.
- **Section Headers & Metric Identifiers:** Emphasize crisp hierarchy with structured line heights, ensuring no overlapping descenders during multi-line wraps.
- **Body Copy:** Maintains an airy `1.5` to `1.55` line-height ratio, using relaxed neutral tones (`#5A6584`) to create high readability alongside vibrant blue accents.
- **Labels & Microcopy:** High tracking (`+0.04em` to `+0.06em`) in small capitals or bolded mini chips to serve as tech-forward category taggers, status pills, and system readouts.

## Layout & Spacing

This design system uses an 8pt architectural rhythm across all containers, grids, and components:

### Grid Architecture
- **Desktop (1280px+):** 12-column layout, max-width `1280px`, outer page margin `margin-lg` (`5rem`), gutter `gutter-lg` (`2rem`).
- **Tablet (768px - 1279px):** 8-column layout, fluid margins `margin-md` (`3rem`), gutter `gutter` (`1.5rem`).
- **Mobile (< 768px):** 4-column layout, minimum margin `margin` (`1.5rem`), gutter `gutter-sm` (`1rem`).

### Rhythm & Vertical Cadence
- **Intra-Component Spacing:** Strictly scaled via `space-xs` (4px) through `space-md` (16px) for tight element pairings (icon-to-label, badge-to-title).
- **Component Breathing Room:** `space-lg` (24px) to `space-xl` (40px) inside cards and form sections.
- **Section Blocks:** Large vertical separations (`6rem` to `8rem`) on desktop to establish an airy, gallery-like product showcase environment.

## Elevation & Depth

Visual hierarchy uses luminous optical layering rather than heavy opaque dropshadows:

- **Level 0 (Flat Canvas):** Clean surface (`#FAFCFF`) occasionally overlaid with an ultra-faint radial gradient glow (`radial-gradient(ellipse at 80% 0%, rgba(19, 102, 255, 0.06), transparent 70%)`).
- **Level 1 (Glassmorphic Tiles & Base Cards):** Background `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(16px)`, enclosed by a 1px border `rgba(6, 10, 35, 0.05)`. Ambient shadow: `0 8px 32px -4px rgba(19, 102, 255, 0.05), 0 2px 8px -2px rgba(6, 10, 35, 0.03)`.
- **Level 2 (Interactive Cards / Floating Modals):** Elevated surface with dynamic dual-gradient border (`linear-gradient(135deg, rgba(19, 102, 255, 0.35) 0%, rgba(0, 198, 255, 0.15) 100%)`). Ambient shadow: `0 20px 48px -8px rgba(19, 102, 255, 0.12), 0 4px 16px -2px rgba(6, 10, 35, 0.04)`.
- **Level 3 (Primary CTAs & Glow Accents):** Active interactive elements cast a localized, saturated aura: `box-shadow: 0 10px 24px -4px rgba(19, 102, 255, 0.35), 0 0 0 1px rgba(19, 102, 255, 0.1)`.

## Shapes

The design system adopts a **Rounded (`2`)** geometry, balancing contemporary mobile OS fluidity with technical precision:

- **Default UI Containers (Cards, Modals):** `rounded-xl` (`1.5rem` / `24px`) to create smooth framing for mockups and complex dashboards.
- **Controls & Form Inputs:** `rounded-lg` (`0.75rem` - `1rem` / `12px` - `16px`) providing comfortable touch targets and ergonomic focus boundaries.
- **Badges, Tags & Interactive Floating Pills:** Fully rounded pill shapes (`9999px`) for quick-scan category tags and floating metadata markers.
- **Inner Embedded Media / Thumbs:** Follows concentric nesting rules: inner corner radius equals outer container radius minus padding.

## Components

### Buttons
- **Primary Action:** Solid vibrant linear gradient (`linear-gradient(135deg, #1366FF 0%, #252BFA 100%)`) with white typography, height `48px` (desktop) / `44px` (mobile), padding `0 24px`, `rounded-lg`. Soft primary blue glow shadow on hover (`box-shadow: 0 8px 20px rgba(19, 102, 255, 0.3)`).
- **Secondary Action:** Frosted white glass background (`rgba(255, 255, 255, 0.9)`), navy typography (`#060A23`), bordered by `1px solid rgba(6, 10, 35, 0.08)`. On hover: subtle cyan-blue gradient outline glow.
- **Ghost / Tertiary:** Transparent background, midnight navy or electric blue text, with interactive hover fill `rgba(19, 102, 255, 0.06)`.

### Glass Cards & Showcase Modules
- Semi-translucent layered backdrop (`backdrop-filter: blur(20px)`), `1px` border using a luminous light-sweep gradient (`border-image: linear-gradient(to bottom right, rgba(19, 102, 255, 0.25), rgba(0, 198, 255, 0.05)) 1`).
- Card padding set to `space-lg` (24px) for mobile, `space-xl` (40px) for prominent desktop case-study previews.

### Chips & Filter Pills
- Pill-shaped (`rounded-full`), height `32px`, font token `label-md`.
- Default: `rgba(6, 10, 35, 0.04)` fill with `#5A6584` text.
- Active: `rgba(19, 102, 255, 0.1)` fill with `#1366FF` text and a refined `1px solid rgba(19, 102, 255, 0.3)` border.

### Input Fields
- Height `48px`, background `rgba(255, 255, 255, 0.8)`, border `1px solid rgba(6, 10, 35, 0.1)`, `rounded-lg`.
- **Focus State:** Border color shifts to `#1366FF` accompanied by a multi-layered aura: `0 0 0 4px rgba(19, 102, 255, 0.12)`.
- Placeholder text in `#8C96AB`.

### Checkboxes & Radio Buttons
- Custom box/circle `20px x 20px`, `rounded-md` (checkbox) / `rounded-full` (radio).
- Default: `1.5px solid rgba(6, 10, 35, 0.2)` on white.
- Checked: Electric cobalt `#1366FF` fill with a crisp white interior icon and soft glow.

### Project Metric & Feature Highlight Displays
- High-contrast numerical metrics utilizing `display-hero` sizing paired with vibrant linear text gradients (`linear-gradient(135deg, #060A23 20%, #1366FF 100%)`).
- Compact metadata labels styled using uppercase `label-sm` with letter spacing `+0.06em`.
